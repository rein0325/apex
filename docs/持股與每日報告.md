## 2. 持股與交易紀錄

> 手機上也可以用網站的「我的持股」頁輸入（資料只存在手機瀏覽器），見 docs/網站與每日自動化.md §2。

**資料只存本機**：`personal/` 整個目錄已被 .gitignore 排除，不會進 GitHub。

以下指令都在 `backend/` 目錄執行。

新增交易（手續費、證交稅沒給就依券商規則自動計算：手續費 0.1425% 無條件捨去、最低 1 元；
證交稅股票 0.3%、ETF 0.1%、債券 ETF 0%）：

```powershell
python -m uv run python -m apex trade --date 2026-11-18 --code 0050 --side buy --shares 100 --price 94.5
```

也可以直接用 Excel 編輯 `personal/trades.csv`，欄位為 `date,code,side,shares,price,fee,tax,note`。

查看持股報告：

```powershell
python -m uv run python -m apex portfolio
```

計算方式：
- **約當股數與市值**：用還原股價計算。現金股利視為再投入，配股、分割自動換算，所以約當股數可能和券商顯示的股數不同，但總報酬一致。
- **成本**：平均成本法，買進成本含手續費。賣出依比例扣成本，已實現損益扣掉手續費與證交稅。
- **帳戶回撤**：用時間加權報酬計算，排除買進、賣出造成的資金進出，只反映價格漲跌。

提醒規則：

| 條件 | 提醒 |
|---|---|
| 帳戶回撤 ≤ −10%、−20%、−25%、−30% | 依程度提醒（使用者目標 −25%、上限 −30%） |
| 單一個股（不含 ETF）占持股 > 30% | 集中度過高 |
| 持股比近 60 日高點低 20% 以上 | 個股跌幅大 |
| 持股最後成交日早於資料日 | 可能停止交易或下市 |

限制：還沒有記錄現金部位，比重只計算持股。

## 3. 候選策略模擬追蹤（紙上交易）

研究過、但沒通過驗證的 4 個候選策略，從 2026-10-30 起每月底記錄「會買哪些股票、各多少比例」，
之後用真實行情計算表現。這是目前唯一能在不動用保留期的情況下，取得新樣本外資料的方法。

| 策略 | 說明 |
|---|---|
| MLP:lgbm:60:15:3:0.6 | 上漲機率 ≥ 60% 才買（防守型） |
| CS:70:D2&ML:lgbm:60:15:3 | 0050 七成（轉弱減碼）＋ML 三成 |
| ML:lgbm:60:15:3 | ML 超額排名前 15 檔 |
| A1:15:3+D3 | 趨勢成長 15 檔（Phase 2） |

規則：
- 訊號一旦記錄就不能修改（資料表 `paper_runs`、`paper_signals`）。
- 記錄時已經過了下一個交易日開盤的，標示為「補記」。2026-10-30 的第一期就是補記，但訊號只用了 10-30 以前的資料。
- 報酬計算：訊號日次一交易日開盤買進，持有到下一期訊號的次一交易日開盤，使用還原價（含股利），並扣掉約略換股成本（來回 0.78%）。
- **這些策略都沒有通過驗證**。報告中的訊號只用於追蹤，**不是買賣建議**。

**期間切分調整（2026-11-19）**：保留期原本是「2025-01 起到最新資料」，會和模擬追蹤重疊，所以改成：

| 期間 | 範圍 | 用途 |
|---|---|---|
| 保留期 | 2025-01-02～2026-10-30 | 最終驗證，只開一次（仍鎖定） |
| 實際追蹤期 | 2026-11-02 起 | 模擬追蹤，只追蹤，不用來挑選或調整策略 |

為了重建緩衝規則等持股狀態，記錄訊號時會用過去約 13 個月重跑策略，但只取最後一天的目標權重，不輸出、也不保存任何績效。

```powershell
python -m uv run python -m apex paper
```

## 4. 每日報告（本機）

```powershell
python -m uv run python -m apex daily
```

流程：
1. 更新資料：行情、公司行動、籌碼、營收財報、指數、休市日。
2. 加 `--record-paper` 時，若已過月底訊號日就記錄模擬追蹤訊號。模擬追蹤以雲端（GitHub Actions）為準，本機一般不加。
3. 產生報告，內容如下，並存到 `personal/reports/YYYY-MM-DD.md`：
   - **市場狀態**：大盤狀態（多頭、空頭、盤整、高波動）、距 200 日均線、波動百分位、站上 60 日均線的比例、加權報酬指數與 0050 的近 1 月／3 月／今年報酬、距一年高點。
   - **持股報告**：§2 的內容。
   - **模擬追蹤**：§3 的績效與最新訊號。

如果資料不是最新（例如交易所尚未公布），報告會明確標示實際的資料日期（規格書 §5.4）。結束代碼為 1，方便排程判斷。

`--no-update` 只產生報告，`--site 目錄` 同時產生公開網站。

**自動執行（選用）**：可以用 Windows 工作排程器，在每個交易日晚上（例如 21:00）執行。這會改變系統設定，需要時請自行建立，或告訴我再提供步驟。

```powershell
schtasks /Create /TN "Apex 每日報告" /SC WEEKLY /D MON,TUE,WED,THU,FRI /ST 21:00 /TR "cmd /c cd /d C:\Users\user\Documents\code\Apex && python -m uv run python -m apex daily >> data\logs\daily.log 2>&1"
```
