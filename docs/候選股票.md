# 台股智慧量化投資決策系統｜候選股票

- 文件版本：0.2
- 日期：2026-11-20；2026-11-21 更新（圖像化介面、小金額配股、策略失效警示）
- 對應：系統規格書 STEP 05B（機器學習預測）、STEP 08 第 3、4 項（候選股票排名、20／60 日預測摘要）；產品企劃書「系統提供分析，是否買進由使用者決定」
- 程式：`backend/src/apex/candidates.py`、`backend/src/apex/vault.py`、`frontend/picks.html`

---

## 1. 內容

每個交易日晚上，模型會挑出 **60 日分數前 30 名**的股票。網站依使用者輸入的總投入金額，從中組出建議組合（§3），每檔附上：

| 欄位 | 意思 |
|---|---|
| 上漲機率 | 過去同等級股票，60 個交易日後是賺錢的比例 |
| 預期中間值（價位） | 過去同等級股票報酬的中間值，換算成價格 |
| 一半落在（價位） | 過去一半結果的範圍（25～75% 分位），依這檔股票自己的波動調整寬度 |
| 平均（扣成本） | 過去同等級股票的平均報酬，扣掉約 0.78% 的來回成本 |
| 20、120 日參考 | 同一套方法的 20、120 日版本（規格書 STEP 05B） |
| 比大盤好的機率 | 過去同等級股票，同期間漲得比加權報酬指數多的比例 |
| 近一年走勢 | 點「看近一年走勢」才載入，還原股價（含股利） |
| 波動、近半年最大跌幅 | 風險參考 |
| 為什麼選它／模型扣分的地方 | LightGBM 特徵貢獻（SHAP）往上推最多的 3 項、往下拉最多的 2 項，附實際數值 |
| 量化條件 | Phase 2 規則是否成立：趨勢、營收成長、獲利改善、法人買進；用來看規則與模型意見一致或衝突 |

## 2. 方法

1. **模型**：LightGBM，46 個特徵（價量、產業、籌碼、營收、財報、市場狀態），超參數沿用 Phase 3，不另外調整。
2. **每天重新訓練**：只用到當天為止「已經知道結果」的樣本。60 日標籤必須在今天以前就已實現，不偷看未來。
3. **分數等級**：今天的分數換成全市場百分位，分成前 2%、前 2～5%、前 5～10%、前 10～20%、前 20～50%、後 50%。
4. **歷史戰績表**：用 2018–2024 每年重新訓練的樣本外預測，統計每個等級的實際持有期間報酬。2025 年以後是保留期與實際追蹤期，不納入。
5. **個股區間**：
   - 中間值與平均：直接用該等級的歷史值。波動大不代表比較會漲。
   - 區間寬度：用「報酬 ÷ 期間波動」的歷史分位，乘上這檔股票目前的波動。

2026-11-19 的歷史戰績（60 日）：

| 等級 | 上漲機率 | 中間值 |
|---|---|---|
| 前 2% | 56% | +1.6% |
| 前 10～20% | 53% | +1.2% |
| 後 50% | 44% | −2.4% |
| 全部 | 48% | −0.7% |

## 3. 依金額建議組合（規格書 STEP 07）

輸入總投入金額後，在瀏覽器裡依固定規則組合：

| 規則 | 內容 |
|---|---|
| 檔數 | 2 萬以下 2 檔、5 萬以下 3 檔、10 萬以下 4 檔、20 萬以下 5 檔、40 萬以下 6 檔，再多 8 檔 |
| 產業分散 | 同一產業最多四成的檔數（至少 1 檔） |
| 走勢分散 | 和已選股票近 60 日日報酬相關係數超過 0.8 的不重複選（不同產業但常一起漲跌的也算） |
| 配置 | 依近 60 日波動反比：波動越大分得越少（Phase 2 研究中可降低回撤） |
| 價格適合（小金額） | 同一個分數等級裡，網站上的預期報酬都一樣，所以優先選「平均每檔分到的錢能買 4 股以上」的股票；其餘照原本名次（2026-11-21） |
| 買不起 | 分到的金額買不起 1 股就跳過，改選下一名 |
| 零頭補滿 | 買完整數股剩下的錢，逐股補給離分配金額最遠、而且買得起的那檔（每檔最多超過分配 25%），讓錢盡量用完（2026-11-21） |
| 試算 | 股數、實際投入（含手續費）、剩餘現金、每檔都在中間值／一半範圍上下緣時的損益（已扣買賣成本） |

### 3-1. 小金額配股（2026-11-21 使用者回饋）

使用者回饋：只有 5,000 元時，推薦的股票一股就上千元，只買得起 2～3 股。

- **股數本身不影響報酬**：同樣投入 5,000 元、漲 5%，買 3 股或 100 股都是賺約 250 元。真正的問題是整數股的零頭用不到、錢分得不平均。
- 改善：同等級優先選價格適合的股票，並把零頭補滿。範例（測試資料，5,000 元、2 檔）：原本會選每股 1,450 元與 2,300 元的股票、各只買 1 股、剩下約 1,250 元；改善後選同等級每股 210 元與 30 元的股票，買 9 股與 103 股，只剩 14 元。
- 被換掉的股票會列在「怎麼配的」裡，寫明原因。

市場亮紅燈時，配股區會提醒「大盤風險高，回測發現減碼能少賠、但也會少賺，由你決定」，但不會自動減少金額（《研究報告/出場規則研究.md》§8）。

### 3-2. 畫面（2026-11-21 改版）

- 配股結果先給一個大數字：3 個月後中間情況的損益，下方的條狀圖是差與好的情況。
- 每檔一張卡片：上漲機率圓環、價格條（黑點＝現價、紅線＝中間值、淡紅＝一半結果的範圍）、量化條件打勾標籤、建議股數。
- 推薦理由、20／120 日參考、損益試算收在「為什麼選它」，點了才展開。

## 4. 持股看法（規格書 STEP 07「建議買進、持有、減碼、賣出或觀望」）

全部可投資股票的評分也放在加密檔裡。「我的持股」頁會用候選股票頁記住的密碼解開，對每檔持股顯示：

| 看法 | 規則（固定、公開） |
|---|---|
| 續抱 | 模型分數在前半段，且股價在季線之上 |
| 留意 | 模型分數在後半段，或股價跌破季線 |
| 考慮減碼 | 模型分數在後 20%，而且股價跌破季線 |
| 不評分 | ETF、成交量太小或資料不足 |

每檔都附上加分與扣分理由、符合的量化條件，以及同等級股票過去 60 日的上漲機率與中間值。

**換股比較**：看法不是「續抱」的持股，會和第一名（尚未持有的）候選股比較：候選股等級的 60 日中間值 − 持股等級的中間值 − 換股成本約 0.8%。大於 1 個百分點才說「換股的預期比較好」，否則說差距小或不划算。

## 5. 實際成績與模型健康（企劃書 3.8、規格書 STEP 10）

雲端每天把前 30 名記錄到 `pick_log`（排名、等級、當時的預期、模型版本、訓練資料截止日），只記一次、不覆蓋。網站「過去推薦的實際成績」顯示：

- **已到期**（滿 60 個交易日）的前 10 名：實際上漲比例、平均、中間值，和當時預期、同期 0050 比較。
- **最近 10 天的推薦**：到目前為止前 10 名的平均報酬、上漲比例、0050 同期。
- **模型健康**：到期樣本滿 50 筆後判斷。
  - 實際上漲比例比「隨便挑」低超過 2 個標準誤 → **失準**，建議暫停參考。
  - 已到期推薦平均比 0050 差、而且差距超過 2 個標準誤（至少 6 個月的推薦）→ **落後大盤**。標準誤以推薦月份為單位計算，並乘上 √3 修正 60 日報酬的重疊，避免一兩個月運氣差就誤報。
  - 比當時預期低超過 2 個標準誤 → **注意**。
  - 其餘為**正常**。
  - 未滿 50 筆時顯示「累積中」。
  - 「失準」或「落後大盤」時，候選股票頁最上方會出現**策略失效警示**，建議先停止照推薦買進。

報酬計算與回測一致：推薦日次一交易日開盤買進，第 60 個交易日開盤賣出（還原價），不扣成本。

## 6. 限制（一定要知道）

- 這個模型在研究中**沒有通過驗證期**，沒有穩定勝過 0050（docs/研究報告/機器學習研究報告.md）。上漲機率只比隨便挑高約 8 個百分點。
- 預期值是歷史統計，不是目標價。實際結果可能落在區間之外：
  - 有四分之一的情況比區間下緣更差。
  - 也有四分之一的情況比區間上緣更好。
- 市場波動大時，區間會很寬。這是事實，不是程式錯誤。
- 候選名單常集中在同一個產業，例如近期的半導體設備。全部買進等於押同一個方向。
- 模擬追蹤（docs/持股與每日報告.md §3）會持續記錄這類策略的真實表現，可以用來判斷可信度。
- 推薦理由是模型的打分依據，不是因果關係。2026-11 的候選多半是「獲利好、但股價已從高點跌 6～7 成」的股票，代表模型偏好跌深反彈，這類股票波動也特別大。

## 7. 隱私與法規

- 候選股票用密碼加密，加密格式為 PBKDF2-SHA256＋AES-GCM，加密後才放上公開網站（`picks.json`）。
- 只有輸入密碼的人能在瀏覽器解開，密碼不會傳到伺服器。
- 這樣做是因為網站是公開的。未持有投顧執照，不能公開推薦特定股票，所以候選名單只給你自己看。
- 密碼存在 GitHub Secrets 的 `APEX_VIEW_PASSWORD`。

## 8. 使用方式

- **網站**：上方「候選股票」，第一次輸入密碼，可以勾選記住。
- **電腦**：`apex daily` 的報告也會附上候選股票（`--no-candidates` 可略過，約省 1 分鐘）。
