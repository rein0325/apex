# 台股智慧量化投資決策系統｜技術選型

- 文件版本：0.1
- 日期：2026-11-15
- 對應：系統規格書 §8 第 3、9 項
- 狀態：第 1～4 階段已決定；第 5 階段為方向，屆時再確認

---

## 1. 決策原則

1. 只決定眼前階段需要的技術，網站相關選型留到第 5 階段。
2. 個人使用、每日收盤後批次運算、資料量數 GB，不採用伺服器型或大數據架構。
3. 資料存取集中在獨立的一層，日後更換資料庫不影響策略與模型程式。
4. 研究結果必須可重現：鎖定套件版本、保存原始資料。

## 2. 已決定（第 1～4 階段）

| 項目 | 選擇 | 理由 |
|---|---|---|
| 語言 | Python 3.13 | 量化與機器學習生態最完整；最新的 3.15 可能還沒有 LightGBM、XGBoost 等套件的支援 |
| 環境與套件管理 | uv（`pyproject.toml`＋`uv.lock`） | 鎖定版本，確保回測可重現 |
| 研究資料庫 | DuckDB | 單一檔案、免伺服器，全市場橫斷面運算快，可直接與 pandas 互通 |
| 原始資料保存 | 依來源／日期保存原始回應 | 規格書要求可追溯；解析程式修正後可重新解析 |
| 資料處理 | pandas＋DuckDB SQL | pandas 與 ML 套件相容；大量聚合交給 DuckDB |
| 執行環境 | 本機（Windows） | 歷史回補與模型訓練較吃資源，研究期不需雲端 |
| 排程 | 手動執行，或 Windows 工作排程器 | 研究期不需 24 小時運作 |
| 測試／程式品質 | pytest、ruff | 各模組需可獨立測試 |
| 版本控制 | git＋GitHub 私人 repo | 依規格書 §5.3 |
| 機密資訊 | `.env`（不進版本控制） | 例如 FinMind token |

## 3. 個人資料原則（規格書 §8 第 9 項）

**持股、現金與交易紀錄只保存在本機，不上傳雲端。**

| 層 | 位置 | 內容 |
|---|---|---|
| 公開分析層 | 雲端（第 5 階段起） | 市場狀態、候選股排名、多週期預測、策略理由、模型健康狀態 |
| 個人層 | 本機 | 持股、現金、交易紀錄、部位計算、績效追蹤 |

- 兩層以「每日分析檔」銜接，檔案內含資料日期、模型版本、候選股與預測，不含任何個人資料。
- 個人建議（股數、減碼等）在本機結合持股後計算。可用本機程式，或在瀏覽器內讀取本機檔案計算（不上傳）。第 4～5 階段再決定。
- 代價：手機只能看公開分析層；交易紀錄需自行備份（之後提供一鍵加密備份）。
