# 台股智慧量化投資決策系統｜策略研究計畫（Phase 2）

- 文件版本：0.2（決定事項已確認）
- 日期：2026-11-19
- 對應：產品企劃書 Phase 2「量化策略研究」；系統規格書 STEP 03、04、05A、§4 驗證標準
- 前提：Phase 1 的資料層與回測框架（docs/資料層設計.md、docs/回測框架.md）

---

## 1. 目標與範圍

**要回答的問題**：趨勢、強勢輪動、成長潛力三類交易邏輯，在扣除成本後，是否**穩定**勝過加權報酬指數與買進持有 0050？

- 三類策略**各自獨立驗證**，不預設哪一類會勝出（規格書 1.2）。
- 「風險調整」不是第四種選股法，而是套在三類策略與 0050 上的**部位控制層**。
- 短期反轉只當對照組或進場濾網。
- 結果可能是「沒有一個策略過關」，這也是有效的結論（規格書 §9 第 4 條：沒有優勢就觀望）。
- **不在本階段做**：機器學習（Phase 3）、策略融合與實際持股建議（Phase 4）。

## 2. 防止過度擬合：資料切分

```
2015 ───── 暖機（計算 240 日指標）
2016-01 ～ 2022-12  研究期（7 年）：設計策略、調參數，可以反覆看
2023-01 ～ 2024-12  驗證期（2 年）：每個候選策略只跑「定版後」的設定
2025-01 ～ 2026-10  保留期（約 2 年）：全部研究結束時**只開一次**，不再修改
2026-11 起          實際追蹤期：候選策略的模擬追蹤，不用來挑選策略（2026-11-19 新增，見持股與每日報告 §3）
```

> 2026-11-21：保留期已在《模型改進研究.md》開啟一次（結果不及格），之後不能再用來挑選或修改模型。

- 研究期包含 2018 貿易戰、2020 疫情崩跌與反彈、2022 空頭，市場狀態夠多樣。
- 研究期內再用**滾動式（Walk-forward）**檢查：每年用前 N 年選參數、下一年測試，看參數是否穩定。
- **試驗紀錄**：每跑一組參數就寫入 `research_trials` 表（策略、參數、期間、指標、時間）。最後報告會列出總試驗次數，並用 Deflated Sharpe Ratio 校正「試很多次挑最好」的運氣成分。
- **參數穩定性**：最佳參數的鄰近參數也要表現接近（高原，不是孤峰），否則視為擬合雜訊。

## 3. 市場狀態（STEP 03）

先用簡單、可解釋的規則，每天收盤後分類：

| 面向 | 規則（初版） |
|---|---|
| 趨勢 | 加權指數相對 200 日均線、200 日均線斜率 |
| 波動 | 20 日實現波動度相對過去 3 年的百分位，> 80% 為高波動 |
| 廣度 | 收盤價高於 60 日均線的股票比例 |

組合成：多頭、空頭、盤整、高波動。本階段的用途：

1. **切分績效**：每個策略分狀態列出報酬、回撤，看它在哪種環境有效。
2. **測試曝險調整**：例如空頭時降低持股，這屬於風險調整層。

HMM 等統計模型留到 Phase 3 與規則版比較。

## 4. 特徵庫（STEP 04）

一次算好、存成面板（日 × 股票），所有策略共用，且只使用當時可取得的資料：

| 類別 | 特徵 |
|---|---|
| 趨勢 | 20／60／120／240 日均線位置與斜率、距 52 週高點 |
| 動能 | 20／60／120／240 日報酬（可排除最近 20 日） |
| 相對強度 | 相對大盤、相對同產業的報酬排名；產業指數動能 |
| 價量 | 成交金額變化、量能放大、量價配合 |
| 波動與風險 | 60 日波動度、下行波動、最大回撤、跳空 |
| 籌碼 | 外資、投信 5／20 日買賣超占成交量比；融資餘額變化、券資比 |
| 基本面 | 月營收年增率、近 3 月對近 12 月營收加速；單季 EPS 年增、毛利率、營益率變化、ROE；負債比 |
| 可交易性 | 平均成交金額、股價、是否處於停止買賣 |

- 月營收在**次月 11 日**、財報依法定期限之後才可使用（資料層 §12）。
- 市值以「股本 ÷ 面額 × 收盤價」估算。

## 5. 候選策略

每類先定 2～3 個**事先寫好的變體**，參數只在有限範圍內測試。共同設定：流動性篩選（`liquid_universe`）、等權重、每月與每兩週調整、持股 5／10／15 檔（見 §9）。

### A. 趨勢成長

找中長期趨勢延續的股票。

- A1：股價在 60／120／240 日均線之上且均線上揚，依距 52 週高點排序。
- A2：A1 再加 120 日報酬排名前段。
- 出場：跌破 60 日均線或跌出排名前段。

### B. 強勢輪動

- B1 產業輪動：先選 60 日動能最強的前 3～5 個產業，再選產業內最強的股票。
- B2 殘差動能：扣除大盤與產業影響後的個股動能，降低追高整個族群的風險。
- B3 相對強度＋法人：相對強度前段，且投信或外資近 20 日買超。

### C. 成長潛力

研究基本面改善、但股價還沒充分反映的股票。

- C1 營收加速：近 3 月營收年增率高於近 12 月，且連續成長。
- C2 獲利改善：單季 EPS 年增、毛利率上升。
- C3 C1／C2 加上股價未過度延伸（例如距 240 日均線不超過 X%）。

### D. 風險調整層（套在 A～C 與 0050 上）

- D1 波動目標：依組合波動度調整總曝險。
- D2 市場狀態曝險：空頭或高波動時降低持股比例、保留現金。
- D3 個股權重：依波動度反比配置，取代等權重。

### E. 對照組

- E1 短期反轉：買過去 5～20 日跌最多的股票，用來確認動能效果是否只是噪音。
- E2 隨機選股：從同一個可投資範圍隨機選同樣檔數，重複 100 次，得到「沒有選股能力」的分布。

## 6. 評估方式

每個策略都輸出同一份報表（規格書 §4）：

1. **全期指標**：CAGR、Sharpe、Sortino、最大回撤、Calmar、勝率、Profit Factor、週轉率、成本拖累。
2. **相對基準**：加權報酬指數、0050、等權重 50、隨機選股分布的百分位。
3. **穩健性**：
   - 逐年報酬，以及打敗基準的年份比例。
   - 分市場狀態的表現。
   - 分市值大小、上市／上櫃的表現。
4. **成本敏感度**：無折扣（目前預設）與 2.8 折兩種成本、滑價 5／10／20 bp。
5. **資金規模**：以你的實際本金與零股、最低手續費 1 元測試，確認小資金不會被手續費吃掉優勢。

### 過關門檻（初版，研究期與驗證期都要符合）

| 條件 | 門檻 |
|---|---|
| 成本後年化報酬 | 高於加權報酬指數與 0050 |
| 風險調整報酬 | Sharpe 高於 0050 |
| 最大回撤 | 不超過 −30%（2026-11-19 決定） |
| 穩定性 | 至少 60% 的年份勝過加權報酬指數；不靠單一年份 |
| 隨機選股 | 高於隨機選股分布的 95 百分位 |
| 參數 | 鄰近參數表現相近 |

過關的策略才能進入 Phase 4 融合；保留期結果會列在最後報告中。

## 8. 工作順序

1. 特徵庫與市場狀態，並驗證特徵沒有前視偏誤。
2. 標準報表、試驗紀錄、隨機選股對照。
3. A 趨勢成長 → B 強勢輪動 → C 成長潛力，各自在研究期設計與調參。
4. D 風險調整層套用在 A～C 與 0050。
5. 候選策略定版，跑驗證期。
6. 開保留期，撰寫研究報告。

| 持股檔數 | 配合小資金，測 5、10、15 檔；搭配零股與最低手續費 1 元 |

## 10. 進度與驗證

### 10.1 特徵庫與市場狀態（2026-11-19 完成）

程式：`backend/src/apex/research/features.py`、`backend/src/apex/research/regime.py`；測試：`backend/tests/test_research.py`。

**特徵庫**：`Features(data)["名稱"]` 取得交易日 × 代號面板，名稱列表見 `Features.names()`。全期（2,892 天 × 2,568 檔）每個價量特徵 0.1～0.6 秒；籌碼第一次載入約 7 秒。

前視偏誤檢查：
- 12 個價量特徵：在第 t 天截斷資料重算，t 的數值與全期計算完全相同（測試）。
- 月營收：台積電 2024-06-07 看到的是 4 月營收（年增 59.6%），6/11 起才換成 5 月（年增 30.1%）。
- 財報：台積電 2024-05-15 看到的是 2023Q4（EPS 年增 −19.3%），5/16 起才換成 2024Q1（+9.0%，與實際 8.70 對 7.98 相符）。
- 產業別：取當時最新一期月營收上的產業別，避免用「現在」的分類回推過去。

抽查台積電 2024-06-28：市值 25.05 兆（實際約 25.1 兆）、毛利率年減 3.2 個百分點、近 4 季 ROE 23.6%，皆合理。

| 2017 | 246 | 0 | 0 | 0 | 0 |
| 2018 | 129 | 40 | 10 | 68 | 0 |

| 2020 | 145 | 1 | 0 | 99 | 0 |

### 10.2 標準報表、試驗紀錄、隨機選股對照（2026-11-19 完成）

程式：`backend/src/apex/research/lab.py`、`trials.py`、`periods.py`、`strategies.py`；測試：`backend/tests/test_research_lab.py`。

```bash
python -m apex research --strategy equal:10 --freq M --freq 2W --random 100   # 預設研究期、本金 30 萬
python -m apex research --strategy A1 --period validation                      # 驗證期
python -m apex trials                                                          # 試驗列表與 DSR
```

- **報表**：策略、加權報酬指數、0050 三欄並列（年化、波動、Sharpe、Sortino、最大回撤、Calmar），加上逐年報酬、分市場狀態、過關檢查。
- **保留期上鎖**：`--period holdout` 或自訂期間跨入 2025 年，沒有加 `--unlock-holdout` 就拒絕執行。
- **試驗紀錄**：每次執行都寫入 `research_trials`，包含策略、參數、期間、成本、指標、程式版本（git commit）。`trials` 指令依同期間的試驗次數與 Sharpe 變異數計算 Deflated Sharpe Ratio。基準不計入試驗次數。
- **隨機選股對照**：與策略相同的可投資範圍、檔數（中位數）、調整頻率與**每次換股比例**，所以成本條件相近。結果存在 `research_random`，相同設定不重算。7 年期間每次約 3 秒。
- **調整頻率**：新增 `2W`（每兩週最後一個交易日）。

試跑「流動性前 10 大等權重」（研究期、本金 30 萬）：年化 7.2%，報酬指數 12.6%，最大回撤 −53%（2018 年被動元件泡沫破裂 −35%）。只挑成交最熱的 10 檔，風險遠高於大盤。七項檢查全部未通過，報表流程正常。

### 10.3 研究期結果：A、B、C、D（2026-11-19）

研究期 2016-01-04～2022-12-30，本金 30 萬，成本為法定手續費無折扣、最低 1 元、滑價 10 bp、允許零股。同期加權報酬指數年化 **12.58%**（Sharpe 0.84、最大回撤 −28.6%），0050 **12.63%**（Sharpe 0.78、最大回撤 −33.9%）。共 84 筆策略試驗，全部記錄在 `research_trials`。

策略寫在 `backend/src/apex/research/strategies.py`。規格寫法：`A1:15:3` 代表 15 檔、緩衝 3 倍（現有持股仍在前 45 名就保留）；`+D3` 代表套用風險調整層。

**第一輪（48 筆）**：8 個事先定義的變體 × 5／10／15 檔 × 每月／每兩週。

| 類別 | 最佳設定 | 年化 | Sharpe | 最大回撤 | 結論 |
|---|---|---|---|---|---|
| A1 趨勢：多頭排列＋近 52 週高點 | 15 檔、每月 | 19.7% | 0.88 | −31.8% | 最有希望 |
| A2 趨勢＋120 日強度 | 15 檔、每月 | 18.2% | 0.68 | −43.2% | 回撤過大 |
| B1 產業輪動 | 15 檔、每月 | 15.4% | 0.61 | −63.8% | 集中在少數產業，回撤極大 |
| B2 產業內相對強度 | 15 檔、每月 | 17.0% | 0.63 | −45.5% | 回撤過大 |
| B3 強勢＋法人買超 | 15 檔、每月 | −2.5% | 0.01 | −51.0% | 無效 |
| C1 營收加速 | 15 檔、每兩週 | 1.5% | 0.18 | −52.5% | 無效 |
| C2 EPS 與毛利率改善 | 10 檔、每兩週 | −0.5% | 0.14 | −61.4% | 無效：常在景氣循環高峰買進（例如 2017 年底的記憶體股） |
| C3 成長＋未過度延伸 | 5 檔、每月 | 13.0% | 0.57 | −35.9% | 只略勝大盤 |

- **每兩週調整全面輸給每月**：多出的換手成本（每年多 4～6%）吃掉了較快反應的好處。之後只用每月調整。
- **5 檔太集中**：結果在不同設定間大幅跳動，雜訊大於訊號。
- 回測引擎驗證：在不計成本時，引擎的報酬與直接用開盤價計算的持股報酬一致；成本拆解（手續費、證交稅、滑價）與成交金額相符。

**第二輪（16 筆）**：A1、A2、B2、C3 的緩衝倍數 3、5。A1 15 檔＋緩衝 3 倍最好：年化 23.0%、Sharpe 1.01、最大回撤 −33.0%。緩衝 2→3→5 的年化為 19.7%→23.0%→15.6%，**不是平滑的高原**，代表參數結果有相當的雜訊。

**第三輪（20 筆）**：風險調整層套在 0050 與前四名上。
- D1 波動目標 20%、D2 市場狀態（空頭或下跌中的高波動時持股 50%）：**都沒有降低趨勢策略的回撤**。月調整反應太慢，2020-03 疫情崩跌在一個月內完成。D2 套在 0050 上可把回撤從 −33.9% 降到 −28.2%，但年化也從 12.6% 降到 11.7%。
- D3 波動反比配置：對 A1 有效，Sharpe 1.01→1.12、回撤 −33.0%→−30.5%、年化 23.0%→21.9%。

**最佳候選 `A1:15:3+D3`**：

| 檢查 | 結果 |
|---|---|
| 勝過報酬指數、0050 | ✓ 年化 21.9%（指數 12.6%） |
| Sharpe 高於 0050 | ✓ 1.12 vs 0.78 |
| 最大回撤 ≤ −30% | **✗ −30.5%**（2019-11 → 2020-03 疫情） |
| 逐年勝率 ≥ 60% | ✓ 71%（輸在 2018、2019） |
| 不靠單一年份 | ✓ 扣掉最好的 2020 年，其餘年份累積超額 +43.9% |
| 隨機選股 | ✓ 高於 100 次隨機選股的全部（隨機中位數 2.9%、95 百分位 8.5%） |
| Deflated Sharpe | 0.69：試了 84 次之後，純運氣的最佳 Sharpe 期望約 0.92；1.12 有一定把握但不算強 |

需要注意：
- **成本很重**：年週轉 7.8 倍、成本拖累每年 4.6%，每月約換掉 68% 的持股。券商折扣對這個策略影響很大。
- **獲利集中在強勢市場**：高波動期（主要是 2020～2021 大多頭）年化 50%，一般多頭時只與大盤相當。
- 研究期其餘策略都沒有接近過關。

### 10.4 驗證期結果：定版候選（2026-11-19）
